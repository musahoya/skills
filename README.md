# 🎯 Claude Skills 제작 도우미 웹앱

Claude 스킬을 작성할 때 Description의 품질을 판단하고, Instructions를 체계적으로 작성하며, 최종 검증까지 도와주는 AI 에이전트 웹앱입니다.

## 🌟 주요 기능

### 1. 📝 Description 판단 에이전트
- 작성한 스킬 description의 구체성과 명확성을 분석
- 100점 만점 점수로 품질 평가
- 구체적인 개선 제안 제공
- 좋은 예/나쁜 예를 기준으로 실시간 피드백

**체크하는 항목:**
- 적절한 길이와 상세도
- 구체적인 동작 동사 사용
- 형식/구조 명시 여부
- 모호한 표현 체크
- 사용 상황과 대상 명시

### 2. ✍️ Instructions 작성 도우미 에이전트
- 스킬 정보를 입력하면 구조화된 Instructions 자동 생성
- 마크다운 형식의 완성된 SKILL.md 템플릿 제공
- 복사 기능으로 바로 사용 가능

**생성되는 섹션:**
- 개요 및 사용 시점
- 입력 정보
- 처리 절차
- 출력 형식
- 품질 기준
- 특별 규칙 및 제약사항

### 3. ✅ 최종 검증 에이전트
- Description과 Instructions의 일관성 검증
- 체계적인 구조 확인
- 실행 가능성 평가
- 최종 체크리스트 제공

## 🚀 사용 방법

### 웹앱 실행하기

```bash
# 방법 1: 직접 파일 열기
open index.html  # Mac
start index.html # Windows
xdg-open index.html # Linux

# 방법 2: 간단한 웹서버 실행
python3 -m http.server 8000
# 그 다음 브라우저에서 http://localhost:8000 접속
```

### Description 판단 탭 사용하기
1. 작성한 description을 입력창에 붙여넣기
2. "판단하기" 버튼 클릭
3. 점수와 상세 피드백 확인
4. 개선 제안 참고하여 수정

### Instructions 작성 탭 사용하기
1. 스킬 이름, 목적, 입력/출력 정보 입력
2. "Instructions 생성하기" 버튼 클릭
3. 자동 생성된 템플릿 확인
4. "복사하기" 버튼으로 클립보드에 복사

### 최종 검증 탭 사용하기
1. 완성된 Description과 Instructions 입력
2. "검증하기" 버튼 클릭
3. 종합 평가 및 체크리스트 확인

## 💡 활용 예시

### Description 작성 예시

**나쁜 예:**
```
문서를 만듭니다.
```
→ 점수: 15/100 (너무 일반적, 상황 불명확)

**좋은 예:**
```
팀의 주간 업무 현황을 '진행 중', '완료', '이슈' 세 가지 항목으로
구분하여 지정된 형식의 보고서를 작성합니다. 각 항목은 글머리 기호로 정리합니다.
```
→ 점수: 90/100 (구체적, 형식 명확, 구조화됨)

## 📚 Claude Skills 가이드 요약

### 스킬이란?
Claude 스킬은 AI에게 내 업무 방식과 노하우를 가르쳐 반복 작업을 자동화하고 생산성을 극대화하는 도구입니다.

### 좋은 스킬의 특징
- 🎯 **집중성**: 하나의 명확한 작업에 집중
- 📜 **명확성**: 혼동 없는 간결한 언어 사용
- ✍️ **구체성**: 추상적이지 않고 구체적인 형식 명시
- ⏰ **적시성**: 언제 사용해야 하는지 명확하게 정의

### 스킬의 기본 구조
```
my-skill/
├── SKILL.md          # (필수) 스킬의 핵심 지침서
├── REFERENCE.md      # (선택) 보충 자료
├── examples/         # (선택) 입출력 예시
├── scripts/          # (선택) 실행 가능한 코드
└── resources/        # (선택) 템플릿, 이미지 등
```

### Description 작성 원칙

**좋은 예:**
- "팀의 주간 업무 현황을 '진행 중', '완료', '이슈' 세 가지 항목으로 구분하여 지정된 형식의 보고서를 작성합니다."
- "고객의 부정적인 리뷰에 대응하기 위한 이메일 초안을 작성합니다. 공감-문제 확인-해결책 제시-사과의 4단계 구조를 따릅니다."

**나쁜 예:**
- "문서를 만듭니다." (너무 일반적)
- "보고서 작성" (구체성 부족)

### 엘리트 스킬 디자인 5원칙
1. **한 놈만 팬다!** - 단일 책임 원칙
2. **설명이 전부다!** - 명확한 Description
3. **보여주는 것이 최고의 스승이다!** - 예시 제공
4. **작게 시작해서 크게 키워라!** - 점진적 확장
5. **AI를 믿되, 검증하라!** - 인간 감독
